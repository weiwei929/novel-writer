# 小说创作器应用 - 第二阶段演示指南

## 🚀 启动演示

### 1. 启动开发服务器
```bash
cd frontend
npm install  # 如果首次运行
npm run dev
```

### 2. 访问应用
打开浏览器访问：http://localhost:3000

## 🎯 演示流程

### Phase 1 成果展示
1. **三栏布局视觉优化**
   - 访问任意项目的编辑页面
   - 观察左侧项目导航、中间编辑区、右侧元数据面板的视觉层次
   - 注意灰色背景、增强边框、分隔线和阴影效果

2. **编辑器显示模式重构** 
   - 使用编辑器时注意单一编辑/预览模式切换
   - 快捷键测试：`Ctrl+P` 切换预览模式
   - 观察预览模式的纸质感背景和排版样式

### Phase 2 成果展示

#### A. 写作模式切换系统
1. **模式指示器测试**
   - 在编辑器页面顶部观察当前模式指示器
   - 悬停查看模式详细信息和历史记录

2. **模式切换器测试**
   - 使用顶部模式切换器在三种模式间切换：
     - 🔵 规划模式（PLANNING）
     - 🟢 写作模式（WRITING）  
     - 🟣 审阅模式（REVIEW）
   - 键盘快捷键测试：`Ctrl+1/2/3`

#### B. 智能右侧面板

1. **规划模式（蓝色主题）**
   - 切换到规划模式观察右侧面板变化
   - 测试章节大纲编辑功能
   - 测试角色设定、场景设定输入
   - 测试情节要点的添加和删除
   - 测试时间线设置功能

2. **写作模式（绿色主题）**
   - 切换到写作模式观察面板变化
   - 开始写作并观察实时统计：
     - 字数计数和目标进度
     - 写作时间追踪
     - 写作速度计算
     - 预计阅读时间
   - 测试写作状态控制（开始/暂停）
   - 观察成就徽章系统

3. **审阅模式（紫色主题）**
   - 切换到审阅模式观察面板变化
   - 查看增强的元数据管理界面

#### C. 高级功能测试

1. **键盘快捷键**
   ```
   Ctrl+1  -> 切换到规划模式
   Ctrl+2  -> 切换到写作模式  
   Ctrl+3  -> 切换到审阅模式
   Ctrl+P  -> 切换预览模式
   Ctrl+S  -> 保存内容
   ```

2. **过渡动画**
   - 观察模式切换时的平滑过渡效果
   - 注意按钮缩放和颜色变化动画
   - 测试悬停状态的视觉反馈

3. **写作专注功能**
   - 在写作模式下测试计时器功能
   - 观察目标进度的实时更新
   - 测试成就系统触发条件
