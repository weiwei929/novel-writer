# 任务卡

本项目采用架构师-操作员协作模式：

- **架构师 (Claude)**：产出任务卡、审计结果、把控架构方向
- **操作员 (Netcatty)**：SSH 进 VPS 执行任务卡中的操作步骤，反馈执行结果
- **转发人 (Pennfly)**：在架构师和操作员之间传递任务卡与反馈

## 任务卡生命周期

```
创建（架构师） → 执行（操作员） → 反馈（操作员→转发人） → 审计（架构师）
                                                                  ↓
                                                     通过 ✅ 或 出修正卡 🔄
```

## 目录结构

```
docs/tasks/
  README.md         ← 本文件
  TASK-XXX.md       ← 任务卡（按序号命名）
  archive/          ← 已完成的任务卡归档
```

## 任务卡格式

每张任务卡包含以下章节：

```
## 背景
为什么做这个任务，前置依赖。

## 操作步骤
逐条可执行的命令/操作，按顺序编号。

## 预期结果
执行成功后应该看到的现象。

## 验证方法
如何确认操作成功（命令 + 预期输出）。

## 回滚方案（可选）
如果操作失败如何恢复。
```
