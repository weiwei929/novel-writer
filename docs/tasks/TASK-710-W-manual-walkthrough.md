- **看什么**：
  - 提示文案是 **「已确认企划并放行至创作室」**
  - 作品进入创作室的 **「待处理」** 区
- **错了长什么样**：
  - ❌ 作品**直接跳成"进行中"**，或章节正文立刻被生成 → 说明还在走旧的 `start-writing`，700-B 没生效

- **看什么**：正文存住了，作品状态变为「已完成」
- **错了长什么样**：保存无提示 / 刷新后正文没了

#### 1-3　提交编审（700-D）★ 关键

- **点哪里**：**作品详情页**（不是创作室列表页）→ 找「提交编审」
- **看什么**：
  - 作品详情页上**存在**这个入口（这正是 700-D 补的）

  - ❌ 作品**直接变成「审阅中」** → 说明直达了 `reviewing`，违反拍板 F（缓冲区语义），**这是要停手回报的**

#### 1-4　开始审阅

- **点哪里**：编审部 → W1 → 「开始审阅」
- **看什么**：作品从「待处理」移到「审阅中」

#### 1-5　标记已审（700-C）★ 关键

- **点哪里**：编审部 → 打开 W1 的**审阅详情页** → 点「标记已审」
- **看什么**：
  - 提示 **「已标记为审阅完成」**
  - **自动跳回审阅任务列表**
  - W1 从「审阅中」移到「已完成」
- **错了长什么样**：
  - ❌ 弹出 **「审阅状态流转将在后续版本接入」** → 这是修复前的假提示，说明 700-C 回退了
