## 一、四级导航结构

```
L1 主导航（5 Tab）
┌──────────────────────────────────────────────────────────┐
│  创意组  │  企划课  │  创作室  │  编审部  │  文集库     │
└──────────────────────────────────────────────────────────┘

L2 子导航（阶段内 Tab，仅创意组/企划课有）
  创意组:
  ┌──────────────────────────────────────────────────────┐
  │  外来参考  │  灵感碎片  │  AI 搜索  │  创意讨论  │  企划建议书 │
  └──────────────────────────────────────────────────────┘
  企划课:
  ┌──────────────────────────────────────────────────────┐
  │  企划建议书  │  作品内容元数据  │  立项评估  │  立项作品 │
  └──────────────────────────────────────────────────────┘

L3 作品级（列表 → 详情页）
  子 Tab → 作品名称列表 → 点击作品名 → 进入详情页操作

L4 章节级（仅创作室）
  编辑器 + 参考面板
```

各阶段的导航深度：

| 阶段 | L2 子 Tab | L3 作品级 | L4 章节级 |
|------|-----------|-----------|-----------|
| 创意组 | 5 个子 Tab | 部分需要（企划建议书列表→详情） | — |
| 企划课 | 4 个子 Tab | 需要（作品列表→详情页） | — |
| 创作室 | — | 需要（作品列表→编辑器） | 编辑器 + 参考面板 |
| 编审部 | — | 需要（作品列表→审阅工作台） | — |
| 文集库 | — | 需要（作品列表→查看） | — |

## 二、阶段间流转：四决策点

每个阶段末尾，进入下一阶段前弹出决策面板：

```
┌──────────────────────────────────────────────┐
│  此作品即将离开当前阶段                        │
│                                              │
│  [继续] ── 进入下一阶段                       │
│  [退回上阶段] ── 回到前一个阶段继续打磨       │
│  [暂存审查池] ── 搁置，不进不退              │
│  [删除] ── 移入回收站，可恢复                 │
│                                              │
│  备注：[________________________]            │
└──────────────────────────────────────────────┘
```

审查池是全局搁置区，不分阶段。用户可以随时从审查池把作品捞回任意阶段继续。

阶段内原则上不设回退机制。但某些节点可配置**删除按钮**（"不玩了"），同样落入回收站。

## 三、阶段 1：创意组

### 3.1 子导航与结构

```

L2 子导航: [外来参考] [灵感碎片] [AI 搜索] [创意讨论] [企划建议书]

```

### 3.2 外来参考

```
功能：文件导入 + 手动点评（可选）
```

### 5.4 章节状态：由保存行为驱动

```
[保存]           → 章节状态保持"创作中"
[保存并标记完成] → 章节状态变为"已完成"
```

不做自动判断。不引入 Writing/Revising 等中间状态的自动切换。用户的两个操作决定了章节两个状态：**创作中 / 已完成**。

全部章节"已完成" → 解锁"提交审阅"按钮。

### 5.5 提交审阅

```
所有章节已完成 → [提交至编审部审阅]
```

编审部**只接受全本审阅**。不支持提前提交部分章节。

"提交审阅"时触发阶段末四决策点：
[继续] [退回企划课] [暂存审查池] [删除]

## 八、全局规则

### 8.1 阶段隔离

五个阶段互相隔离，不建复杂跨阶段互联。字段随流程携带的规则：

```
创意组 → 企划课: 仅传递 企划建议书（梗概+创新点+参考引用清单）
企划课 → 创作室: 仅传递 立项作品（元数据+章节规划）
创作室 → 编审部: 仅传递 全本正文（已完成章节）
编审部 → 文集库: 仅传递 定稿作品（最终版）
```

不在中途随意加行李。

### 8.2 审查池

全局搁置区，不分阶段。作品进入审查池后：
- 阶段信息保留（知道从哪来的）
- 可重新捞回原阶段继续
- 或在原决策点直接删除

### 8.3 删除 = 回收站

所有"删除"操作（阶段末决策或阶段内"不玩了"按钮）均为软删除，落入回收站。

回收站规则：
- 可恢复（捞回原阶段或任意阶段）
- 可定期清空（确认后永久删除）
- 回收站是全局限的，不分阶段

### 8.4 灵感碎片图库

- 图片仅存储在创意组内置小图库
- 不跟随项目流转
- 碎片本身不涉及图片上传时不阻塞操作

### 8.5 Collection 语义迁移

工程问题，内部处理。方案：原地重定义 Collection 为"文集"，现有数据兼容。

## 九、AI 开关与阶段对应

| Agent | 所属阶段 | 默认 |
|-------|---------|------|
