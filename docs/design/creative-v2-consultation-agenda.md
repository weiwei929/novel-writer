## 会诊范围

**第一组**（结构裁决）：

1. 创意缘起用什么承载？
2. 旧 `_evaluation` 如何处置？
3. 作品预期是否硬门槛、存哪里？

**第二组**（来源池裁决）：

4. 灵感碎片 / 外来参考 / AI 搜索 如何接入 v2 链路？

**明确不属于本次范围：**

- 616-B（作品设定最小模型、旧六字段去留、WorldBuilding 处置）

## 第一组裁决（已定案）

### 裁决 1 · 创意缘起

**先用 `Proposal` 承载，不新建实体。**

| 项 | 内容 |
|----|------|
| 载体 | 现有 `Proposal` 记录 |
| 阶段区分 | `Proposal.metadata._creativeStage` |
| 建议枚举 | `origin`（创意缘起）→ `conceiving`（创意构思）→ `formed`（创意作品成形） |
| 原则 | 缘起与构思是同一作品生命的前后半段，不是独立业务对象 |
| 跳过缘起 | 允许直接「新作品创意构思」，创建时 `_creativeStage = conceiving` |
| revisit 条件 | 仅当「多条缘起 routine 合并为一部作品」成为常态需求时，再单独立项新实体 |

---

### 裁决 2 · 构思备注（原 `_evaluation`）

**产品层 `_evaluation` 退场；构思备注为新概念。**

| 项 | 内容 |
|----|------|
| 产品/UI 称谓 | **构思备注**（不再使用「评估意见 / 讨论评估」） |
| 新写入键 | `Proposal.metadata._creativeNotes` |
| 读取规则 | `_creativeNotes ?? _evaluation`（旧数据只读兼容） |
| 旧键 `_evaluation` | legacy 冻结；不扩展、不在新 UI 强调 |
| 与 `synopsis` 分工 | 梗概 = 可交接的「故事讲什么」；构思备注 = 过程痕迹 / 澄清记录 |
| 禁止 | 提交时自动用备注覆盖梗概 |

---

### 裁决 3 · 作品预期

**创意组阶段可选；企划课接收前补强。**

| 项 | 内容 |
|----|------|
| 616 对齐 | 创意组种子阶段「作品预期」为**可选**（不抬升为提交硬门槛） |
| 创意组提交 | 硬门槛：**标题 + 梗概**；作品预期缺项可提示，不阻断 |
| 企划课 | **接收 / 正式立项前**应已补强作品预期（软→硬递进） |
| 暂存位置 | `Proposal.metadata._workExpectation` |
| 立项同步 | 双写至 `Project.metadata._workExpectation`（类比 616-A2 梗概双写模式） |
| 禁止复用 | `innovation`、`coreSetting`、`description` |

## 第二组裁决（已定案）· 三个创意来源

### 总原则

**三个来源保留为来源池，统一出口为「生成 / 创建创意缘起」。**

```text
灵感碎片 ──┐
外来参考 ──┼──→ 创意缘起 ──→ 创意构思 ──→ 创意作品 ──→ 待企划作品
AI 搜索  ──┘
```

> 三个创意来源**不直接生成创意作品**，只生成或启发「创意缘起」；创意缘起经作者确认与补全后，才进入创意构思。

**禁止的旧心智（v2 不再强化）：**

- 绑定作品
- 引用进作品（ReferencePicker 式强绑定）
- 直接生成提案 / 进入企划课

来源池各自独立，**出口统一**，作品生命线统一。

---

### 裁决 4 · 灵感碎片

| 项 | 内容 |
|----|------|
| 定位 | 作者随手记下的短想法 |
| 保留 | 继续作为创意来源池独立存在 |
| 产品动作 | **由此创建创意缘起**（取代「引用到作品」） |
| 生成结果 | 新建 `Proposal`，`metadata._creativeStage = origin` |
| 带来源信息 | `来源类型：灵感碎片`；`来源说明：来自某条灵感碎片`（自由文本，可含碎片标题/摘要） |
| 禁止 | 不写入 `references[]` 强绑定；不直接创建 `conceiving` / 待企划作品 |

---

### 裁决 5 · 外来参考

| 项 | 内容 |
|----|------|
| 定位 | 较长材料：文章、文档、摘录等 |
| 保留 | 继续作为创意来源池独立存在 |
| 产品动作 | **由此提炼创意缘起**（取代「引用到建议书 / 作品」） |
| 生成结果 | 新建 `Proposal`，`metadata._creativeStage = origin` |
| 缘起草稿 | 标题可空；梗概由作者填写或 AI 辅助（远期）；作品预期可空 |
| 带来源信息 | `来源类型：外来参考`；`来源说明：来自某个外来参考` |
| 禁止 | 不把整篇材料强绑定进作品；complete/partial 处理类型仅描述**来源材料**，不决定作品是否成立 |

---

### 裁决 6 · AI 搜索

| 项 | 内容 |
|----|------|
| 定位 | **远期**创意来源池（当前可占位） |
| 产品动作 | **将搜索结果保存为创意缘起** |
| 生成结果 | 可编辑的缘起草稿 → `Proposal`，`_creativeStage = origin` |
| 带来源信息 | `来源类型：AI 搜索`；`来源说明` 记录检索主题 / 会话摘要 |
| 禁止 | AI 不直接创建创意作品；不直接进入企划课 |

---

### 来源 metadata 约定（草案）

与第一组裁决衔接，缘起阶段 Proposal 建议携带：

| 键 | 说明 |
|----|------|
| `_creativeStage` | `origin` |
| `_sourceType` | `灵感碎片` / `外来参考` / `AI 搜索` / `直接写入` |
| `_sourceNote` | 来源说明（自由文本） |

可选弱关联（非强绑定）：`_sourceRef: { type, id?, title? }` — 仅追溯，不作为作品成立前提。`_sourceRef` 是否结构化留待实现战役。

## 与 616-B 的边界

| 本裁决（创意组 v2 第一组 + 第二组） | 616-B |
|-------------------------------------|--------|
| 创意组产出什么、阶段如何划分 | 作品设定**最小字段集** |
| 缘起 / 构思 / 作品 / 待企划 链路 | 作品章节模型 |
| `_creativeStage`、`_creativeNotes`、`_workExpectation`、`_sourceType`、`_sourceNote` | 旧六字段 / `settings` / 背景设定去留 |
| 来源池 → 缘起统一出口 | WorldBuilding 是否重启 |
| 进入企划课交接什么（基础信息种子） | AI prompt 最终结构 |
| 构思备注 vs 梗概 产品分工 | |

**616-B 仍负责作品设定最小模型**；本文件不启动 616-B，不替代其会诊。
