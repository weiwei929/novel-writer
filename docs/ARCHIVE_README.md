# 文档归档说明

本目录用于存放已归档的历史文档，这些文档可能包含过时的信息或已被新文档替代。

## 归档原则

1. **过时文档**: 包含过时技术信息或已被新文档替代的文档
2. **历史记录**: 保留作为项目历史记录的重要文档
3. **临时文档**: 开发过程中的临时文档和草稿

## 当前归档内容

- `archive/`: 历史开发文档和状态记录
- `archive/2025_12_11logs/`: 2025年12月清理的过时日志和报告
- `development/`: 开发过程中的规划文档（部分可能已过时）
- `technical/`: 技术问题记录（部分已解决）

## 注意事项

- 归档文档仅供参考，不应作为当前开发的依据
- 如需参考历史信息，请先查看最新的文档（如 `CODING_STANDARDS.md`、`thinklogs/2025-12-08_Tech_Stack_Evaluation.md`）
