## 🎯 分类说明

### 📋 Requirements - 需求与设计
- **目的**：面向产品的需求规格和设计文档
- **内容**：产品需求、UI设计、功能规格
- **受众**：产品经理、设计师、业务人员

### 🏗️ Architecture - 系统架构
- **目的**：核心技术架构和系统设计文档
- **内容**：技术架构、实现规格、设计决策
- **受众**：架构师、技术负责人、资深开发者

### 🚀 Development - 开发过程
- **目的**：动态的开发过程记录和规划
- **内容**：技术成就、开发日志、未来规划
- **受众**：开发团队、项目管理者

### 🏆 Milestones - 里程碑记录  
- **目的**：项目重要节点和版本记录
- **内容**：版本发布、重要成就、阶段总结
- **受众**：项目干系人、管理层

### 🔧 Technical - 技术专项
- **目的**：具体技术问题的深度分析
- **内容**：问题解决方案、技术调研、专项研究
- **受众**：技术专家、问题解决者

### 📦 Archive - 历史归档
- **目的**：过时文档的保存和参考
- **内容**：历史版本、废弃方案、过期文档
- **受众**：需要历史参考的开发者
