# 学习档案索引

> **状态**：学习记录 · 不作为操作依据 · 最后核对 2026-07-27
>
> 这里存放本项目的**思考过程**——讨论、会诊、复盘、评估、随笔。
> 它们记录「当时为什么这么想」，不记录「现在该怎么做」。
> **要知道现在该怎么做，读 [`../ROADMAP.md`](../ROADMAP.md) 和 [`../CURRENT_BASELINE.md`](../CURRENT_BASELINE.md)。**

本项目首先是一个学习项目。这些记录是刻意留下的资产，**一份未删**。

---

## 怎么用这份索引

三个维度，按需选：

- **按主题** —— 想回顾某一类问题是怎么想清楚的
- **按时间** —— 想看认知是怎么演进的
- **按结论是否仍成立** —— 最重要的一列。当年的结论，今天未必还对
