## 🔧 核心组件详解

### 数据管理层
- `backend/src/services/database.ts`: 统一数据访问接口
- `backend/src/types/database.ts`: 数据模型定义
- 支持文集、项目、章节的完整生命周期管理

### 用户界面层
- `frontend/src/components/collections/CollectionsList.tsx`: 文集管理界面
- `frontend/src/components/projects/ProjectsList.tsx`: 项目管理界面
- `frontend/src/components/editor/MarkdownEditor.tsx`: 核心编辑器
- `frontend/src/pages/SettingsPage.tsx`: 设置配置界面

### API服务层
- `backend/src/routes/api.ts`: 统一API路由
- `backend/src/routes/collections.ts`: 文集API
- `backend/src/routes/projects.ts`: 项目API
- `frontend/src/services/api.ts`: 前端API客户端

## 🎮 功能使用指南

### 基础使用流程
1. **创建文集**: 访问文集管理页面，创建新的文集容器
2. **添加项目**: 在项目管理中创建具体的小说项目
3. **开始写作**: 进入编辑器开始创作内容
4. **管理设置**: 通过设置页面配置应用行为

### AI助手使用
1. 访问设置页面 (`/settings`)
2. 配置 Grok API Key
3. 启用 AI 助手开关
4. 在编辑器中使用 AI 写作功能
