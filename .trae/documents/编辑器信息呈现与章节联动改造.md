## 目标

* 在编辑器顶部清晰呈现项目与当前章节元数据，保持单视图编辑/预览。

* 修复并强化左侧章节点击联动，切换章节即加载内容并高亮选中。

* 在右侧提供可折叠的“章节元数据”面板，用于本章设定编辑与保存（不显示字数统计）。

## 顶部元数据栏

* 在 `EnhancedEditorPage.tsx` 顶部栏补充项目与章节信息：

  * 项目：`title`、`author`、`status`、`wordCount`、`chapterCount`、`updatedAt`

  * 章节：`order`、`title`、`status`、`wordCount`、`updatedAt`

* 在现有“项目元数据”按钮旁新增“章节元数据”按钮：

  * 点按后打开右侧抽屉显示 `ChapterMetadataPanel`（见 components/editor/ChapterMetadataPanel.tsx）。

* 保持现有“未保存更改/已保存时间”提示逻辑。

## 左侧章节联动

* 确认 `ProjectNavigationPanel` 章节项 `onClick` 调用父级的 `onChapterSelect`（已传入）。

* 在 `EnhancedEditorPage.tsx` 的 `handleChapterSelect`：

  * 如有未保存变更，先触发 `handleSave`，再 `navigate('/editor/:chapterId')`。

  * 保持 `useEffect([chapterId])` 重新加载章节；维持 `key={chapterId}` 强制刷新编辑器。

* 视觉联动：通过 `currentChapter` 属性让左侧列表高亮当前章节；无反应时排查事件绑定与路由跳转是否被阻止（加 `cursor-pointer` 与明确 `button` 类型）。

## 右侧“章节元数据”面板

* 使用现有 `ChapterMetadataPanel` 作为内容组件，右侧抽屉宽度 `w-80`：

  * 字段：`synopsis`（概要）、`characters`（角色）、`tags`、`notes`、`summary` 等（从 `chapter.metadata` 读取）。

  * 保存：调用 `chaptersApi.updateMetadata(chapterId, field, content)` 与 `chaptersApi.saveMetadataVersion(...)`（组件已有接口封装时沿用）。

* 抽屉交互：

  * 顶部“章节元数据”按钮开/关抽屉；切换章节时同步更新抽屉数据。

  * 不显示写作统计；仅呈现当前章节设定。

## 保存策略

* 保持“手动保存 + 退出提醒（beforeunload）”，避免打断写作专注。

* 章节元数据面板内提供独立保存按钮；保存后提示成功，不自动影响正文保存状态标识。

## 路由与状态

* 路由维持 `'/editor/:chapterId'`；`useParams` + `useEffect([chapterId])` 重新加载。

* 顶部栏新增显示字段来自 `project` 与 `chapter` 当前状态；右侧抽屉读取 `chapterId` 与 `chapter.metadata`。

## 风险控制

* UI 改造保持最小侵入：不更改现有编辑/预览逻辑。

* 数据写入均通过既有 API 模块；失败时仅提示，不影响正文内容。

## 验收与验证

* 路径：项目页 → 进入编辑器 → 顶部栏显示完整元数据 → 左侧点击章节切换 → 右侧抽屉编辑本章设定并保存。

* 验证：

  * 后端日志返回 200；前端网络面板无错误。

  * 切换章节后编辑器内容与顶部栏均更新；抽屉内容随章节刷新。
